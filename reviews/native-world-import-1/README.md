# Native room worlds and same-ROM audio import

Candidate `native-world-import-1`, on `implementation/native-world-import-2026-10-19`, preserves parent `f11a797bc71b62464d7e485fca5cfd4c5e1be02a`. The deliverable is the standalone `app/mainline/NES_Forge_2.0.0-alpha.11.html`; no new ZIP, beta promotion or main merge is included.

**RE / DISASM → Open spatial RE workbench → Prepare editable assets → Import into current project → Open imported World** creates room geometry and reusable metatile libraries. Worlds retain the selected room's left-to-right page arrangement and initial art at project Y=0; receipts preserve native origin and page offsets. Each source cell has the same four patterns and palette; collision is unassigned. Capacity splits are explicit and never invent native transition markers. V2 bundles carry worlds; v1 stays readable as its original scene/pose/clip adaptation. Ordinary schema-12 projects already support these canonical fields, so no schema bump is required. IDs/references remap on append; one Undo reverses spatial import.

**Recover / import audio** opens the same RE ROM in the existing Audio library without loading/replacing live emulation. Preview/import music or a supported single-channel SFX, then Save Project As to retain both worlds and audio. Audio remains a separate project transaction and is not inside the spatial bundle. Music replaces order and tempo/speed; existing SFX timing follows the new tempo. DPCM and short-mode noise stay native evidence/playback, not tracker transcription. The browser checks use Ninja music command 42 and SFX command 14, plus Zelda title `$01` music and game SFX `$EF/$02`, at finite bounded windows. These are tested selections, not claims about every cue or full song fidelity.

Collision, entities/AI, native connections, event bindings and full executable game reconstruction remain incomplete. Existing ROM export requires all world-used metatiles to be linked in the included tileset scene; definitions used only on later imported pages can require further authoring before ROM export. Project JSON and v2 bundles preserve the full editable geometry independently of ROM capacity. No CPU/APU/PPU, runtime compiler or world codec changes were made.
