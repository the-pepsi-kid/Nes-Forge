# Startup repair: owner checks

Open the newly downloaded `NES_Forge_Retro_Workstation_Startup_Fixed.html`.

- Confirm **Retro Workstation** and the density selector appear in the upper toolbar. Toggle the skin and choose Compact/Comfortable.
- Confirm **Resources** opens its explorer, preview and relationships. Try Follow selection and an editor shortcut with a saved project.
- Confirm the working-context ribbon and **Connected Workspace** appear. Open Overview, Create a Game, Native / Z2, Project Health and Import Preview.
- Confirm Metasprites shows source context and can open a matching pose.
- Open an existing native project. Confirm Area Library/native World navigation and ordinary save/reopen work.
- On Punch-Out, confirm the Glass Joe replay shortcut opens above the existing Play view without losing the canvas or controls.

The strict DOM checks exercise startup and control wiring. Browser layout, mouse/paint geometry, physical devices, listening and hardware remain separate acceptance checks. The existing per-title tutorials and supported native writer boundaries still apply.
