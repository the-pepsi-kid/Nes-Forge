WHAT THIS SLICE DOES
- Recognizes one linked FamiTone2 v1.11 profile from validated instruction/data
  structure and mapped pointers, without a filename or whole-ROM hash allowlist.
- Decodes bounded native music structure, commands, referenced instruments and
  envelopes, timing/timer evidence and statically established SFX data.
- Edits supported one-byte note/cut and existing-instrument commands on an
  isolated same-layout ROM copy. Native Undo/Redo and ROM/evidence exports keep
  the original source intact and report shared byte uses.
- Leaves the active Forge project and loaded emulator unchanged. Playback of
  an exported copy is an explicit, separate load in an emulator.

WHAT IT DOES NOT DO
Canonical AUDIO tracker import is unimplemented. These are native-driver data
and native ROM edits, not Forge patterns or full editable project recovery.
Native session history is not saved by Save Project As. Export the ROM/evidence
before starting another native analysis or closing the page.

This profile does not cover every FamiTone build, other audio drivers, banked
mappers, control-flow/stream-size changes, DPCM recovery/edits, SFX byte editing
or complete dynamic SFX inventory. Unknown or ambiguous inputs remain
inspectable with explicit limits.
