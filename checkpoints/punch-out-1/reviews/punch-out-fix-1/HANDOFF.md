# Punch-Out intake and capture correction

The preceding release's direct-decoder checks did not cover the ordinary Import ROM path. That path attempted a runtime capture while MMC2 tracing was disabled. The background-template test also forced vertical mirroring and compared an incomplete staging state to the same incomplete assumptions. Those checks did not establish a clear, complete scene.

New imports through Import ROM and Open ROM / project prepare a completed native frame first. An unstarted source advances in bounded, yielding batches to frame 600, after startup PCM. An already-running source at or beyond that point uses its current completed frame. The Scene contains editable native tile rows, scanline palettes/masks/scroll and OAM; it is validated against both completed background and composite framebuffers. There is no screenshot overlay or quantization fallback. A frame with unsupported changing OAM geometry refuses rather than producing a mismatched scene.

Audio restores from the preserved original source after import and reopening, including ordinary captured projects without an investigation record. Native-source navigation enables Source Audio and displays the actual 84-entry catalog instead of reporting zero/unresolved. Header padding bytes 12–15 can vary while semantic fields and protected source/audio bytes remain checked. Exact input/output headers remain preserved.

The v2 template decoder uses horizontal mirroring for the source's horizontal contexts and the actual FD/FE fill for each physical nametable. Champion-result background colors come from palette offset zero; offset $20 is a sprite-palette override. The unfaded zero-palette slot is unavailable. These remain partial background templates, not complete fights or dynamic screens. The initial Scene is the pixel-validated frame; a readable Game Over template is the first native recipe page.

The original v1 decoder is retained byte-for-byte. Existing v1 saved projects keep their original projections and recipes and still build. Re-import the original ROM to create the corrected captured scene. Captured reference pixels are savable/editable copies; native ROM output still refuses unsupported edits to them. Native writing applies only to the declared 574 source-template literal bytes. Native Audio/sample writing remains unavailable.

Evidence: gate/Summary.json (97 public checks, nine suites), Intake_Verification.json (12 actual workflow groups), Catalog_Verification.json (four full-catalog/recipe preservation groups), Source_Preservation.json (150 unchanged predecessor bundle inputs, seven reviewed seams, two added modules). The older 403 checks remain historical and are not represented as current reruns. Browser listening, physical devices, complete fights and hardware timing remain open. MMC2 video remains the existing approximate scanline model; capture exactness is against its completed frame.
