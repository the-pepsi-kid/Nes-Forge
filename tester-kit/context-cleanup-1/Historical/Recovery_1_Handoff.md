## Meaning of the current workflows

The new [Recover, edit and build guide](Guides/Recover_Edit_Build.html) explains
three distinct operations: investigate/run the source, import supported editable
resources, and preserve/build a supported native Zelda II source with explicit
location-field edits. An editable room World is not the complete overworld.
Audio import is separate, finite and does not infer stage music/SFX bindings.

Native source/recipe backups preserve original code and supported edits. General
art/World/Audio/runtime edits may be saved but block native builds without an
encoder. Coordinate edits do not repaint terrain or prove a safe reachable route.

The requested shared Stage → Scene selection across Scene/World, collision,
actors/animation, Audio and Code/RE remains an **unfinished product requirement**.
It needs explicit context, shared-asset references, provenance, coverage and
compatible encoders; no new parallel gameplay model is introduced by this guide.
