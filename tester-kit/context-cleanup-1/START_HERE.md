# NES Forge — complete documented recovery kit

**2.0.0-alpha.11 / context-cleanup-1 · Context cleanup-1 · unpromoted candidate**

Extract the whole ZIP to a short folder such as `C:\NF`, keeping its files
together. Open [START_HERE.html](START_HERE.html), then **Open NES Forge**.

1. New to Forge? Follow the original [nine-step first-game tutorial](Tutorial.html).
2. Returning to the native ROM work? Open [Recover, edit and build](Guides/Recover_Edit_Build.html).
3. Keep the [user guide](Guide.html), [manual](Manual.html), [operator reference](Reference/Operator_Reference.html) and [Audio workshop](Guides/Audio.html) nearby.
4. Save actual native JSON checkpoints with **Save Project As**, confirm they
   exist, reopen, then build again. Native-game projects contain your input ROM;
   keep those backups private.
5. Report the exact build and steps using [Feedback_Template.txt](Feedback_Template.txt).

The original tutorial, manuals, PDFs, illustrations and all 127 original
delivery documents are retained. They include historical feature descriptions;
the recovery guide explains the newer workflows and their limits. Original
identity/launcher files replaced by current copies remain under `Historical`.
