# Historical documentation — September 30, 2026

These documents, control table and illustrations preserve the original NES Forge 1.9.0 alpha kit. They do not identify the application at this kit's root and are not current test results or a current roadmap.

The original `NES_Forge_Alpha_Review_Kit_2026-09-30` archive remains a separate historical deliverable. It contains the original application, source ZIP and evidence. Those application/source archives are not duplicated in this alpha.11 tester kit. A historical file's relative source/evidence links refer to that original archive; open the current kit's Manual or Operator Reference for working navigation.

- `Documentation_Source/` contains all six original Markdown source documents verbatim.
- `Release_Docs/` contains all seven original release-document copies verbatim.
- `From_Scratch_Tutorial_1.7.md` retains the earlier workshop source.
- `../Control_Index.csv` preserves all 439 original control rows; it is a 1.9.0 baseline index, not an inventory of every alpha.11 control.
- `../../images/` preserves the two historical editor illustrations. They are not fresh alpha.11 screenshots.
- `PRESERVATION_RECORD.json` records file identities for this preservation set.
