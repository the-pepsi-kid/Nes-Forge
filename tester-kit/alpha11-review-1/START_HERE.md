# NES Forge alpha test kit

**App:** 2.0.0-alpha.11 / source-intake-1 · **Project schema:** 12  
**Status:** pre-release alpha candidate; feedback welcome.

1. Extract this ZIP to an ordinary short folder, such as `C:\NF\AlphaTest`. Keep
   `NES_Forge.html` and the other files together. On desktop, open
   `NES_Forge.html` in a normal browser, then `Tutorial.html` beside it.
   A ZIP preview or file-viewer thumbnail is not the running editor.
2. Follow tutorial steps 1–9, starting with **New Project**. Save native JSON
   checkpoints with **Save Project As…**. Confirm each file actually appears
   in the selected location or browser downloads. Keep the `.nes` ROM as a
   separate executable output; it is not your editable project backup.
3. Reopen the final native JSON with **Open Project**, build again, and fill out
   `Feedback_Template.txt`. Return your feedback to the person who sent the
   kit through the same channel. Nothing is submitted automatically.
4. `NEXT_STEPS.html` contains optional artwork and Scout exercises. Mobile,
   sound, controller, source and ROM-recovery checks are optional and should
   be marked **Not tested** if not attempted.

If the browser refuses to open the local editor, request a hosted copy of the
**same build** from the kit sender and record the access issue as **Blocked**.
You are not expected to bypass browser warnings or publish/host the ZIP.

Read `KNOWN_LIMITS.html` for the supported scope and `SOURCE_RECORD.json` for
the exact app identity. The package does not include source history or outside
game ROMs. Share only your own or permitted project assets in feedback.
