# NES Forge alpha test kit

**2.0.0-alpha.11 / source-intake-1 · Kit RC2 · Pre-release**

Open [START_HERE.html](START_HERE.html) for the designed kit launcher. Extract the ZIP to a short folder such as `C:\NF\AlphaTest` first, keeping all files together.

1. Open [NES Forge](NES_Forge.html) and the [tutorial](Tutorial.html) in separate tabs. Start a new project after saving any restored work.
2. Follow tutorial steps 1–9, saving portable project JSON checkpoints. Reopen the final project and build again.
3. Try the [optional second session](NEXT_STEPS.html), [review checklist](Reference/Reviewer_Checklist.html), or [mobile triage](Reference/Mobile_Performance_Triage.html) if relevant.
4. Return the [feedback form](Feedback_Template.txt) through the channel that supplied the kit. Nothing is submitted automatically.
