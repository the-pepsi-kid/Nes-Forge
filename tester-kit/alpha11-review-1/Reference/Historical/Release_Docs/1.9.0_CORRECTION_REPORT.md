## Explicit limitations

- Single-room GP16/layout-3 ROMs do not embed schema-12 Gameplay Core source. Reopening is explicitly partial, restores Gameplay Core as disabled/empty, retains original bytes for Run Original and directs creators to native JSON/ZIP backups. No ROM-format change is implied. WG17 World source reopening remains checked and lossless for the covered Gameplay Core data.
- `syncActiveFromPersistent` is a one-way alpha/profile action. It may deactivate an active Actor. Once inactive, that Actor's evaluator is skipped and cannot observe the reverse value until reconstruction. This is not physical Door blocking or a generalized reversible gate system.
- The mapper-0 profile supports 12 executable Actor Instances in its whole plan and 64 one-byte persistent values. Canonical authoring may retain unreachable Actors outside that executable plan with diagnostics.
