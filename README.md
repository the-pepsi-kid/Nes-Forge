# NES Forge

A complete NES development environment in a single HTML file.

## Features

- **Scene Editor** — 256x240 nametable editing with attribute overlays
- **CHR Editor** — Tile/pattern table editing with usage heatmaps
- **Sprite Editor** — OAM management with 8x8 and 8x16 mode support
- **Palette Editor** — Full NES palette with per-scene palettes
- **Code Editor** — 6502 assembler with syntax highlighting
- **Audio Tracker** — NES APU sound design
- **Collision Editor** — Per-tile collision type assignment
- **Animation Editor** — Sprite animation sequencing
- **Emulator Integration** — Load ROMs, capture frames/nametables

## Usage

Open `nes-forge.html` in a browser. No build step required.
