A3 — Triangle pitch matches the authored note
Open Pulse_Triangle.nesforge.json in the same example folder; Build & Run.
Expected repeating sequence:
  Pulse A4 -> Triangle A4 -> Pulse A5 -> Triangle A5.

should match, although pulse and triangle sound different. A5 is an octave
above A4. Triangle should not drop an octave when switching from pulse.
Runtime timer rounding is expected; low-note hardware limits are documented.
