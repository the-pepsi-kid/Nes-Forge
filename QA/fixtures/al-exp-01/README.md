# AL-EXP-01 synthetic fixtures

Original test cartridges for the experimental discovery foundation
([docs/architecture/AGENT_LAB_EXPERIMENTS.md](../../../docs/architecture/AGENT_LAB_EXPERIMENTS.md)). Every byte is
generated from a seed by `generate.cjs`: the program comes from its own small assembler (`asm6502.cjs`), and the tiles,
palettes, maps and filler come from a seeded generator. There is no commercial or third-party content. Apache-2.0,
like the rest of Forge.

## The cartridge

The cartridge is iNES NROM-128: 16 KiB PRG and 8 KiB CHR-ROM. It carries the marker `NESFORGE-SYNTHETIC/1 …` at the
start of its last 256 PRG bytes. Forge's experiment runner accepts only cartridges with this marker.

**Program and screens.** The program draws one of four 16×15 screens of 2×2 metatiles:
- Right cycles three training screens;
- B shows the withheld screen;
- Select switches the background palette set.

**What the seed decides:**
- the table's layout: interleaved records or split arrays;
- the quadrant order: row or column;
- its size (36–60 records), stride and position;
- the palette array's encoding (low or high two bits);
- mirroring;
- the decoys: an exact copy (some seeds), a copy in the other quadrant order, a partial copy, a repeated record and a
  fake palette array;
- three alias pairs.

**For the access-role tests,** the program reads one of its own opcode bytes as data, which makes that byte dual-use.
It writes the attribute table through a mirror address and writes palette entry $3F10.

## Files

| File | Use |
|---|---|
| `seeds.json` | Pinned seeds, roles and SHA-256s; `demoSeed` is the panel's cartridge |
| `roms/` | The committed cartridges; regenerated byte for byte by `--check` |
| `truth/` | What the generator built: table geometry, records, palettes, maps, decoys, code listing, known-effect patches, the expected screens. Used only by the oracle and by runner tests that need a known effect, never by discovery |
| `oracle.cjs` | The independent judge of a candidate definition and its reconstruction; imports nothing from `app/` |
| `generate.cjs`, `asm6502.cjs` | Generator and assembler |

## Seeds

- **Development (1–7, 7 with a trainer):** used while the discovery code was built.
- **Acceptance (5902787) and generalization (101, 202, 303, 404):** withheld, and run only by the acceptance suite.

## Commands

```bash
node QA/fixtures/al-exp-01/generate.cjs --check
```

```bash
node QA/fixtures/al-exp-01/generate.cjs --write
```

```bash
node QA/fixtures/al-exp-01/generate.cjs --seed 9 --out /tmp/fixture
```

`--write` rewrites every committed file and the editor's demonstration module; rebuild the editor afterwards. `--seed`
writes one extra fixture outside the repository.

`tools/verify_public_profile.py` identifies these cartridges by their pinned SHA-256 and marker. Any other cartridge in
the tree fails it.
