## Scope and exclusions

Implemented localhost-oriented wallet sign-in, server-owned shared player state, World loading, local persistence, camp/XP experiment, shared side views, original Link source-derived pose selectors, test-only server combat and live edits. Native Zelda II movement, enemies, hitboxes, animation timing, all scenes and ROM-to-host parity remain incomplete. Host is bound to localhost; do not expose it publicly.

**Public Git exclusions:** proprietary ROMs, private game-specific observations/screenshots, local SQLite/wallet state, admin credentials, bytecode/caches, generated distribution ZIPs. Do not commit test user data.
